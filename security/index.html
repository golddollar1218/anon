Automated tests

114 tests pass: cryptographic proofs, adversarial and fuzz cases, consensus faults, backup recovery, swap/launch duplicate protection, never-resend rules, token and quote parsing.

Incident response

If a flaw is found: affected mainnet features are switched off in code and republished, a notice goes on this page and on X (@AnonymousCash_). Report issues via X DM. ANON holds no funds, so there is nothing to freeze or recover on ANON's side.
